# Me-v16

> 老工具图形化重制版 · 一站式移动端逆向辅助工具箱

## 简介

Me-v16 是一款面向移动端安全研究的图形化工具箱，将常用的命令行逆向工具重新封装为可视化界面，降低使用门槛、提升操作效率。主要面向 iOS / Android 应用安全分析场景，涵盖动态脱壳、APK 静态分析等核心能力。

## 功能特性

### 图形化封装

- 将传统命令行逆向工具整合为统一的图形化界面
- 点选式操作，无需记忆复杂命令参数
- 操作流程可视化，降低新手入门成本
- 支持自定义frida脚本

### iOS 动态脱壳

- **支持 Pixel 设备**：在 Pixel 手机上对 iOS 应用进行动态脱壳（dump decrypted binary）
- 基于运行时内存 dump，绕过 App Store 加密保护
- 一键导出解密后的可执行文件，便于后续静态分析
- 支持批量脱壳与结果管理

### APK 简单分析

- Android 应用包快速解析
- 提取基础信息：包名、版本、权限、签名、组件清单等
- APK 结构浏览与资源查看
- 适合快速摸底，复杂分析建议配合 jadx / apktool 使用

## 环境要求

- 操作系统：macOS（主开发与运行环境）
- iOS 脱壳：需 Pixel 设备一台，并完成相关环境部署
- Android 分析：已安装 JDK 运行环境
